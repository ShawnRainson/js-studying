Вопрос 1

Что выведет?

function greet(name) {
    console.log(`Hello, ${name}`);
}

greet("Alex"); - Hello, Alex

Что здесь является параметром, а что аргументом? - name - параметр, Alex - аргумент

Вопрос 2

function multiply(a, b = 2) {
    return a * b;
}

console.log(multiply(5)); - 10
console.log(multiply(5, 3)); - 15

Вопрос 3

В чём разница?

function sum(a, b) {
    return a + b;
} - Обычная функция

и

const sum = (a, b) => a + b; - Стрелочная функция
По факту функционал один и тот же, но стрелочную мы можем использовать как переменную в дальнейшем

Вопрос 5

Что такое callback?

Объясни своими словами на примере:

function execute(fn) {
    fn();
}

Ответ: Ну из того что я понял, callback это по сути функция которая является параметром другой функции, которая взаимодействует с другим параметром этой функции

Вопрос 6

Что выведет?

function show(...numbers) {
    console.log(numbers);
}

show(1, 2, 3, 4); - [1, 2, 3, 4]

Какой тип данных будет у numbers? - ну по идее это коллекция, а именно список

Вопрос 7 🔥

Что здесь происходит?

const double = x => x * 2;

const result = double(5);

Объясни пошагово.
1 Объявлена стрелочная функция double, которая увеличивает переданный параметр x в 2 раза
2 Создана константа result, значением которой является результат использования функции double с числом 5
