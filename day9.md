Вопрос 1. Чем синхронный код отличается от асинхронного? - в синхронном коде операции выполняются по порядку, в асинхронносм нет

Вопрос 2. Что делает setTimeout()? - устанавливает время через которое выполнится операция

Вопрос 3. Почему этот код выведет сначала B, а затем A?
console.log("A");

setTimeout(() => {
    console.log("C");
}, 1000);

console.log("B");


Подсказка: здесь есть подвох в формулировке — внимательно посмотри на задержку и порядок.
Ответ: Подвох в том, что сначала выводится A, потом B, последним выводится C, он стоит после A, но так как для него установлено время после которого он выполнится, он становится в очередь, сначала выполняется синхронный код, а потом асинхронный, даже если бы у C была задержка 0, он бы всё равно выполнился последним

Вопрос 4. Что такое callback-функция? - функция которая передаётся другой функции

Вопрос 5. Что такое Call Stack? - стек выполнения функция

Вопрос 6. Для чего нужны Web APIs? - для работы с браузером

Вопрос 7. Что делает Event Loop? - следит за порядком Call Stack

Вопрос 8. Какие три состояния может иметь Promise? - ожидание, выполнение, отклонение

Вопрос 9. Для чего используются resolve() и reject()? - первое обрабатывает успешное выполнение программы, а второе обрабатывает ошибку

Вопрос 10. Чем отличаются .then(), .catch() и .finally()? - первое срабатывает при успешном выполнении программы, второе при неудачном, а третье всегда независимо от результата

Вопрос 11. Что делает async с функцией? - с async функция автоматически возвращает Promise

Вопрос 12. Для чего нужен await? - для того чтобы дождаться результата Promise внутри async функции

Вопрос 13. Почему await не блокирует весь JavaScript? - потому-что он всего лишь приостанавливает выполнение текущей async функции

Вопрос 14. Что выведет код и почему?
console.log("A");

Promise.resolve().then(() => {
    console.log("B");
});

setTimeout(() => {
    console.log("C");
}, 0);

console.log("D");
Ответ: A, D, C, B, потому что сначала идёт синхронный код то есть A, D, потом асинхронный C, а потом микрозадача, то есть Promise B
